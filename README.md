# Seif Elmahalawy — Portfolio

A modern responsive portfolio built with React + Vite.

## Requirements
- Node.js 18+ recommended
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

The production output is generated in `dist/`.

## Deploy

This is a static Vite site. It can be deployed to GitHub Pages, Vercel, Netlify, Cloudflare Pages, Render, or another static host.

For GitHub Pages, update the Vite `base` value if you deploy under a repository path such as `/portfolio/`.
